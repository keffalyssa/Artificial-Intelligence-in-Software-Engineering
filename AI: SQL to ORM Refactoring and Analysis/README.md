# AI: SQL to ORM Refactoring and Security Analysis

## 1. Task Overview
This folder contains the prompt formulation, initial procedural Python code, refactored SQLAlchemy ORM implementation, and security/maintainability analysis for migrating raw SQL queries to an Object-Relational Mapping framework.

## 2. Files Included
- `initial_code.py`: The original procedural script using `mysql.connector`.
- `refactored_orm.py`: The refactored version utilizing SQLAlchemy declarative models, session handling, and ORM queries.
