# AI: Dynamic Web Lab Generation for Core CSS Concepts

This folder contains interactive single-file HTML/CSS/JS web applications generated via sequential AI prompting to visualize core layout mechanisms.

## Files Included
* `box-model-lab.html`: An interactive tool allowing real-time manipulation of box model properties, side-specific padding/margins, and display types.
* `flexbox-grid-playground.html`: A dynamic playground for testing Flexbox and CSS Grid parameters seamlessly.

## AI Workflow Used
1. Initial baseline prompt for MVP box model structure.
2. Iterative refinement prompt for side-specific controls and border-radius.
3. Independent modular prompt for the Flexbox/Grid layout playground.
